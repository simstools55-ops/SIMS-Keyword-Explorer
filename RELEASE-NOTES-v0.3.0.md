# SIMS Keyword Explorer v0.3.0 Release Notes

This release starts the real Blue Ocean external discovery route.

Key principle:
Do not generate another keyword from an existing high-performing keyword.
Instead, understand the site's Search Audience, then ask Doctor to find
new official changes, new failures, new features, feature endings, or new problems
that this audience is likely to search next.

External discovery remains human-auditable:
SKE decides WHO/WHAT to search; Doctor verifies the live web and SERP.
